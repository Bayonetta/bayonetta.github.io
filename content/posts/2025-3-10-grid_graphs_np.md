在研究室梳理网格图（Grid Graph）上的路径规划与组合优化文献，1982 年发表在 *SIAM Journal on Computing* 上的这篇《Hamilton Paths in Grid Graphs》（Alon Itai, Christos H. Papadimitriou, Jayme Luiz Szwarcfiter）是绝对绕不开的基石文献。这几天终于有空把整篇证明的理论脉络与归约细节完整过了一遍。

网格图作为无限网格图 `G^{\infty}` 的顶点诱导子图，天生具备极其优美且严格的**二分图（Bipartite Graph）结构**——顶点的奇偶性（Even/Odd）完全由其坐标和的奇偶决定。我们平时接触的很多棋盘路径问题或机器人网格巡航，本质上都在寻找一条经过所有顶点的哈密顿路径（Hamilton Path, HP）或哈密顿回路（Hamilton Circuit, HC）。

这篇论文最精妙的地方在于，它完美展现了网格图约束下复杂度结构的戏剧性分化：**通用网格图即使限制在二维平面内依然是强 NP-complete，但一旦几何约束收紧到规则的矩形网格（Rectangular Grid Graph），问题却存在极为优雅的多项式时间充要条件与线性构造算法。**

## 通用网格图的 NP-完全性：保奇偶嵌入与 Gadget 构造

论文在第 2 节首先给出了一个重量级结论：在一般网格图上寻找哈密顿回路与哈密顿路径是 NP-complete。这也顺带为 Euclidean TSP（欧氏旅行商问题）提供了一个比 Papadimitriou 1977 年原始证明更为简洁直观的新证明。

### 1. 归约基座与保奇偶嵌入（Parity-Preserving Embedding）
证明的起点是**最大度不超过 3 的平面二分图的哈密顿回路问题**（已知为 NP-complete）。为了将抽象的二分图 $B = (V^0 \cup V^1, E)$ 映射到几何网格中，作者提出了「保奇偶性嵌入」：
- 把 $V^0$ 中的顶点映射到矩形网格的偶数顶点（$v_x + v_y \equiv 0 \pmod 2$）；
- 把 $V^1$ 中的顶点映射到矩形网格的奇数顶点（$v_x + v_y \equiv 1 \pmod 2$）；
- 二分图中的边映射为网格中顶点不相交的路径。

### 2. 核心构件：9-Cluster 与 Tentacle（触手通道）
为了在网格中模拟原图顶点的连接与覆盖，论文设计了两个极其精妙的逻辑构件：
- **9-Cluster（9-聚类方块）**：将原图中的每个顶点放大为一个 $3 \times 3$ 的 9 顶点网格块。Lemma 2.3 证明了无论路径从哪个角进入、哪个角出去，9-Cluster 内部总能找到一条经过全部 9 个顶点的哈密顿路径。
- **Tentacle（触手）**：由一系列最小维度为 2 的条带（Strip）连接构成的管道，用以替换原图的边。触手具有两种关键的路径覆盖模式：
  - **Cross path（穿越路径）**：从触手一端起点穿越到另一端终点，对应原图边被选入哈密顿回路；
  - **Return path（折返路径）**：从触手起点出发并在同端折返，对应原图边未被选入哈密顿回路。

通过将放大的 9-Cluster 与 Tentacle 正确拼合，原图是否存在哈密顿回路，就精确等价于构造出的网格图 $G_9$ 是否存在哈密顿回路。

> **Theorem 2.1 & Corollaries**：网格图上的哈密顿回路与哈密顿路径问题均为 NP-complete。将网格节点视为城市、距离设为网格路径长度，直接推导出 **Euclidean TSP 是 NP-complete**，且避免了浮点数距离精确度带来的烦琐计算。

## 矩形网格图的充要条件：颜色兼容性与三类禁用配置

当网格图的形状限定为规则矩形 $R(m, n)$ 时，复杂性出现了彻底的反转。论文第 3 节完整给出了矩形网格图 $(R(m, n), s, t)$ 存在 $s$-$t$ 哈密顿路径的充要条件。

### 1. Color Compatibility（颜色兼容性）
由于网格图是二分图，哈密顿路径上的顶点颜色必然交替出现：
- **偶数矩形（$m \times n$ 为偶数）**：黑白顶点数量相等（$|V^0| = |V^1|$），因此哈密顿路径的起点 $s$ 与终点 $t$ 必须**异色（奇偶性不同）**；
- **奇数矩形（$m \times n$ 为奇数）**：多数颜色顶点比少数颜色多 1 个（$|V^0| = |V^1| + 1$），因此起点 $s$ 与终点 $t$ 必须**同为多数颜色（即均在偶数顶点）**。

### 2. Forbidden Configurations（三大禁用配置 F1 - F3）
仅满足颜色兼容并不足以保证哈密顿路径的存在，连通性与几何切割会产生三类不可解的「死角」配置：
- **(F1) 1-维矩形割点**：$G$ 为 $1 \times n$ 矩形，且 $s$ 或 $t$ 不是端点角块（起点/终点切断了唯一的线性连通路径）。
- **(F2) 2-维矩形非边界边**：$G$ 为 $2 \times n$ 矩形，且 $st$ 是一条非边界边（即 $s$ 与 $t$ 相邻且连线将网格横向切断）。
- **(F3) `3 × 偶数` 矩形特殊分离割集**：形如 `G = R(m, 3)` 且 `m` 为偶数，`s, t` 的位置组合在拓扑上形成了无法同时兼顾覆盖的死区。

一个哈密顿路径问题被称为 **Acceptable（可接受的）**，当且仅当它满足颜色兼容性，且不属于 F1、F2、F3 中的任何一种禁用配置。

## 求解机制：Stripping、Splitting 与素问题穷举

为了证明「可接受性（Acceptability）即充分性」，论文提出了一套基于递归降维的归纳证明体系：
1. **Stripping（剥离）**：若能从矩形边缘剥离出一个宽度为 2 的条带 $S$，使得剩余子图 $(R - S, s, t)$ 依然保持可接受，则原问题可由子图的哈密顿路径无缝拓展得到。
2. **Splitting（分割）**：通过一条边 $pq$ 将矩形分割为两个子矩形 $R_p$ 与 $R_q$，若 $(R_p, s, p)$ 与 $(R_q, q, t)$ 均可接受且有解，则拼接两段路径即可得到原问题的解。
3. **Prime Problems（素问题）**：无法继续进行剥离或分割的极小规模问题。Lemma 3.2.4 证明了所有的素问题尺寸均满足 **$(n, m) = (4, 5)$ 或 $n, m \le 3$**。由于素问题数量有限，通过手算穷举验证可知所有可接受的素问题皆存在哈密顿路径。

> **Theorem 3.2**：矩形网格图 $R$ 中存在从 $s$ 到 $t$ 的哈密顿路径，当且仅当 $(R, s, t)$ 是 Acceptable 的。该判定可在 **$O(1)$** 时间内完成，而路径本身的构造算法时间复杂度为与路径长度成正比的 **$O(nm)$** 最优线性时间。

## 归纳与复杂度对比

将论文中关于网格图哈密顿问题的复杂性全景汇总如下表：

| 图结构类型 | 问题类型 | 端点约束 | 计算复杂度 | 核心证明依据 / 算法机制 |
| :--- | :--- | :--- | :--- | :--- |
| **通用网格图** (General Grid Graph) | Hamilton Circuit / Path | 任意 / 给定 $s, t$ | **NP-complete** | 归约自平面 3-度二分图 (9-Cluster + Tentacle) |
| **矩形子网格图** (Subgrid Graph) | Hamilton Circuit / Path | 任意 / 给定 $s, t$ | **NP-complete** | 在网格图空洞中填充长路径归约 |
| **矩形网格图** (Rectangular Grid Graph) | Hamilton Path Decision | 给定 $s, t$ | **P ($O(1)$ 时间)** | 检查 Color Compatibility + 排除 F1-F3 禁用项 |
| **矩形网格图** (Rectangular Grid Graph) | Hamilton Path Construction | 给定 $s, t$ | **P ($O(nm)$ 线性)** | Stripping / Splitting 递归降维至素问题拼接 |

### 思考与 Open Problems

读完整篇论文，最强烈的感受是**图的拓扑约束与其几何对称性对复杂度产生的巨大扰动**。通用网格图只要存在任意形式的「空洞（Holes）」，就能轻松编码 NP-complete 的逻辑 Gadget；而矩形网格图依靠严密的边界对称性，使得全局巡航退化为了局部 Stripping/Splitting 的组合规约。

作者在 Concluding Remarks 中留下了一个极其经典的未决问题：**对于无孔洞（Hole-free）的非矩形网格图（即 `G` 与 `G^{\infty} - G` 均为连通图），哈密顿回路问题是否存在多项式时间算法？** 这个 Open Problem 也为后来几十年网格图路径规划与机器人覆盖算法的研究指明了方向。
