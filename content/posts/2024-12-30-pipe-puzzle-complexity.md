在研究室看组合谜题的文献，上原老师他们 2019 年发表在 IEICE TRANS 的这篇《On Computational Complexity of Pipe Puzzles》（Shirayama, Shigemura, Otachi, Miyazaki, Uehara）是绕不开的经典底色。之前组会讨论时老师就提过这篇，今天把整篇证明和推导细节从头过了一遍。

平时我们做的拼图（Jigsaw）或者边缘匹配谜题（Edge Matching），本质上都在考察「局部一致性」——只要相邻图块边缘咬合或花色相同就行。但水管谜题（Pipe Puzzle）最大的质变在于引入了一个全局约束：**从源点 `s` 到汇点 `t` 必须用管道连通，不能漏水，且整个盘面上严禁生成任何孤立的局部环路（Local Loop）**。

正是这个「全管道可达」的强连通约束，让它的复杂度边界在不同棋盘尺寸与卡片类型下展现出非常有意思的分水岭。

## 三种连接模型与五类管道卡

论文里讨论的水管谜题，卡片均为单位正方形，支持旋转。除了全空的空白卡（Blank）外，基本管道卡分为五类：
- `I`：直管，连接两相对边；
- `L`：弯角，连接两相邻边；
- `T`：三通分支，连接三条边；
- `+`：十字分支，连接全部四条边；
- `X`：立体交叉，两条管道交叉但互不相通（无分支连通）。

根据管口如何对接，论文形式化了三种连接规则（Connection Rules）：
1. **Uniform 模型（统一模型）**：最基础的模型，所有管道居中且粗细相同，任意管口只要相对即可直接对接。
2. **Thickness 模型（粗细模型）**：每个管口有自己的粗细规格，只有粗细完全一致的接口才能对接。单张卡片内部管道粗细可以渐变，卡片旋转后各边缘属性是对称变换的。
3. **Height 模型（偏移/高度模型）**：管道偏离中心，用边缘距离卡片底部的偏移量 `h ∈ [0, 1]` 标记高度。两张卡片水平拼合时，左卡右边缘的高度 `h_i` 必须与右卡左边缘满足 `h_i = 1 - h_j`（原点在卡片自身坐标系下）。注意，Height 模型下卡片旋转会破坏上下对称性。

棋盘给定为 `w × h` 的矩形网格，边界上给定起点 `s` 和终点 `t`。卡片总数记为 `m`，网格格数 `n = wh`。

## 1×n 棋盘上的戏剧性分水岭

整篇论文里读起来最拍案叫绝的一处，是 `1 × n` 棋盘上卡片「用完」与「有剩」之间的复杂度断层。

Bosboom 等人在 2017 年的经典论文中证明过，普通的 Jigsaw 和 Edge Matching 哪怕缩到 `1 × n` 的单行棋盘上，依然是强 NP-complete。但水管谜题在 `1 × n` 上如果要求卡片全部用完，却能直接降解。

### 易解：卡片全用完（m = n）时是欧拉回路

> **Theorem 2**：在 `1 × n` 棋盘上，给定 `n` 张卡片且必须全部用尽（`m = n`），水管谜题在 Thickness 和 Height 模型下均可在 **`O(n)` 线性时间** 内求解。

不失一般性，在 `1 × n` 上填满且不漏水，只能全用 `I` 型卡（端点在左右两端边界）。

- **Thickness 模型的线性算法**：
  把所有出现的粗细规格看作图的顶点集 `R = {r_1, r_2, ...}`。每张 `I` 型卡有两个管口粗细 `{r_i, r_j}`，直接对应图中的一条无向边。接着在起点粗细 `r_s` 和终点粗细 `r_t` 之间连一条虚拟辅助边 `{r_s, r_t}`。
  此时原谜题是否有解，等价于**多重图 `G` 是否存在一条包含该虚拟边的欧拉回路（Eulerian Cycle）**！
  欧拉回路的充要条件众所周知：图连通且每个顶点的度数均为偶数。这只需要一遍线性扫描统计度数和连通块，完全可以在 `O(n)` 时间内搞定。把虚拟边拿掉，就是一条合法的管道摆放序列。

- **Height 模型的线性算法**：
  因为对接规则是 `h_i = 1 - h_j`，构造一个二色多重图 `G = (H, E_b ∪ E_r)`：
  黑边集 `E_b` 代表卡片本身（管口高度对 `{h_l, h_r}`），外加一条连接端点的虚拟黑边 `{1 - h_s, h_t}`；
  红边集 `E_r` 代表几何匹配：对每个高度 `h_i`，必须有对应数量的 `1 - h_i` 配对边。
  原问题有解，等价于在图上找一条**红黑交替的偶长欧拉回路**。充要条件简化为：图连通，且在每个顶点上，相连的黑边度数恰好等于红边度数。同样在线性时间内可判定。

### 难解：允许卡片剩余（m > n）时变回 NP-complete

> **Theorem 1(1)**：在 `1 × n` 棋盘上，如果从 `m` 张卡片（`m > n`）中挑出 `n` 张填满棋盘，水管谜题在 Thickness 和 Height 模型下均是 **NP-complete**。

一旦允许挑卡片，哪怕只有一行，问题立刻从欧拉路径退化成了**哈密顿回路（Hamiltonian Cycle）**。

论文直接将 **3-正则图（Cubic Graph）上的哈密顿回路** 归约过来：
- 对 3-正则图 `G = (V, E)`，把顶点看成粗细（或高度），每一条边 `{v_i, v_j}` 制成一张对应的 `I` 型卡，总共制作 `|E|` 张卡片。
- 棋盘长度设为 `n = |V|`，两端点设为同一顶点 `v_0`。
- 证明的关键在于排他性：如果某个顶点 `v_i` 在选中的卡片序列中被访问了两次，序列里就会出现 4 个带有 `v_i` 粗细的管口；但这与原图 `G` 是 3-正则图矛盾（包含 `v_i` 的边总共只有 3 条，最多提供 3 个管口）。
- 因此，任何合法摆放必定无重合地恰好走过每个顶点一次，正好对应一条哈密顿回路。

允许挑卡，就把「全边遍历（欧拉）」击穿成了「全点恰好一次访问（哈密顿）」。这个反差非常漂亮。

## 3-Partition 与 Frame 框架构造

当所有卡片必须全部用完（`m = n = wh`）时，棋盘只要宽度扩大到 2 行以上，难解性就再次浮现。

论文证明 Theorem 1(2) 和 1(3) 时，用到了一套极为工整的 Frame（外框）构造方法，核心归约目标是强 NP-complete 的 **3-Partition 问题**：
- 给定多重集 `A = {a_1, ..., a_3m}`，`∑ a_i = mB`，问能否划分为 `m` 个子集，每组三数之和均为 `B`。

### 1. 2×n/2 棋盘与分支卡（Theorem 1(2)）

构造一个 `2 × (m(B + 1) + 1)` 的网格：
- 利用厚度/高度可自由设计的特性，像普通拼图咬合一样，先用特定管口唯一锁死一个「红色框架管道」（直径或高度统一设为 1/2）。这个框架唯一的摆放方式就是在网格内留出 `m` 个尺寸为 `1 × B` 的空白槽位。
- 针对 3-Partition 中的每个数 `a_i`，制作一组由 `I`、`L`、`T` 卡片连成的特定小构件，归一化后总长度为 `a_i`。
- 想要将全部卡片无缝塞入盘面且不漏水，必须把这 `3m` 条小管道恰好三两拼合、严丝合缝地填进那 `m` 个长度为 `B` 的空槽里。这当且仅当 3-Partition 有解。

### 2. k×n/k 棋盘且完全无分支（Theorem 1(3), k ≥ 3）

很多组合谜题如果禁止分支卡（只留直管 `I` 和弯头 `L`），复杂度经常会大幅下降。但这篇论文证明：**只要高度 `k ≥ 3`，哪怕一张分支卡都没有，依然是 NP-complete**。

为了在没有分支的情况下把 `a_i` 长度的管道塞进多行网格，论文做了一个很精细的几何变换：
- 对 3-Partition 实例做线性放大：`a_i' = 2a_i + 1`，`B' = 2B + 3`。
- 这个变换强制让每个目标槽位的长度 `B'` 变成奇数。
- 奇数长度允许一条单纯由 `I` 和 `L` 构成的蛇形折返管道（Snake-like Path），在高度为 `k ≥ 3` 的矩形区域内连续折返后，端点恰好能够无矛盾地接出槽位外壁，不需要任何 `T` 或 `+` 分支打辅助。

这套把数值放大并引入奇偶校验消去分支的技巧，在很多网格图路径编码中都非常实用。

## 固定高度下的 FPT 与前沿线 DP

既然任意变化的管口会让问题迅速变难，那最平庸的 **Uniform 模型（所有管口一模一样，中心对称对接）** 到底难不难？

论文给出的答案是：**在棋盘高度 `h` 为常数的前提下，Uniform 模型可以在多项式时间内求解，并且是关于高度 `h` 的固定参数可解（FPT）算法。**

> **Theorem 3**：在 Uniform 模型下，若棋盘高度 `h` 是常数，水管谜题可在 `O(h^{h+2} n^3)` 时间和 `O(h^{h+1} n^3)` 空间内求解。

### 前沿线（Frontline）状态设计

算法采用动态规划，按列优先从上到下逐格推进：`(1,1) → (1,2) ... → (1,h) → (2,1) ... → (w,h)`。

在放置第 `(i, j)` 格之前，已放置卡片与未放置区域之间有一条锯齿形的边界，称为**前沿线（Frontline `F`）**。前沿线上恰好包含 `h + 1` 条待匹配的卡片边缘。

算法的核心在于：如何用有限的状态记录前沿线上管口的连通拓扑，同时防止生成闭合环路？
- 给前沿线上的每个边分配一个标签：
  - `ℓ_0`：该边缘没有引出管道；
  - `ℓ_s`：该边缘引出的管道已和起点 `s` 连通；
  - `ℓ_1, ℓ_2, ..., ℓ_h'`：尚未和起点相连的其他活动连通分支。
- **无环性质带来状态收敛**：因为每条尚未连到 `s` 的开放路径在前沿线上至多贡献两个端点，所以独立路径分支数 `h'` 绝不会超过 `h / 2`。
- 算法每推进一步，就对前沿线上的标签做一次规范化重新编号（Canonical Renumbering），把状态空间锁在 `O(h^{h+1})` 之内。

### 推进与合法性判定

DP 状态数组定义为 `S[u_B, u_I, u_L, c_1, ..., c_{h+1}]`，记录已用掉的各类型卡片数量及前沿线上 `h + 1` 个边的连通标签。

放卡时重点处理两类情况：
1. **新增路径**：放 `L` 卡引入两个新端点，分配一个最小的未用标签 `ℓ_k`，并重新编号。
2. **合并路径**：放 `L` 卡连接前沿线上已有管口 `c_j = ℓ_k` 和 `c_{j+1} = ℓ_k'`。
   - 若 `k ≠ k'`：说明把两条独立路径接上了，合并两端标签为 `min(k, k')`；
   - 若 `k = k'`：说明两条管口来自同一个连通分支。**此时若没有分支卡，这就闭合出了一个局部环路，直接判为非法并剪枝**；如果允许分支卡（`T` 或 `+`），则必须检查前沿线上是否还有其他标为 `ℓ_k` 的管口，若有方可放行。

当扫完整个棋盘最后一列后，只需检查是否最终只剩下一个带 `ℓ_s` 的管口，且位置恰好对准汇点 `t`。

整个转移每步耗时 `O(h)`，总时间复杂度为 `O(h^{h+2} n^3)`。当 `h` 固定时，这是非常标准的多项式解法。

## 归纳与几点思考

整理这篇论文的脉络，水管谜题的复杂度全景大致如下：

| 棋盘规格 | 接口模型 | 卡片条件 | 计算复杂度 | 证明方法 / 核心依据 |
| :--- | :--- | :--- | :--- | :--- |
| `1 × n` | Thickness / Height | `m = n`（全用完） | **P（线性时间 `O(n)`）** | 转化为多重图的欧拉回路判定 |
| `1 × n` | Thickness / Height | `m > n`（卡片有剩） | **NP-complete** | 归约自 3-正则图哈密顿回路 |
| `2 × n/2` | Thickness / Height | `m = n`（含 `I`, `L`, `T`） | **NP-complete** | 归约自 3-Partition（带咬合 Frame 构造） |
| `k × n/k` (`k ≥ 3`) | Thickness / Height | `m = n`（**仅 `I`, `L`，无分支**） | **NP-complete** | 归约自 3-Partition（奇数长度蛇形折返） |
| `w × h` (`h = O(1)`) | Uniform | `m = n` | **P / FPT (`O(h^{h+2} n^3)`)** | 前沿线状态压缩与路径规范化 DP |

### 值得留意的未决问题

上原老师在 Concluding Remarks 里列了几个非常耐人寻味的 Open Problem：
1. **`2 × n` 棋盘且仅允许 `I` 和 `L`（无分支）**：Theorem 1(2) 的 2 行构造高度依赖 `T` 型分支卡；而 Theorem 1(3) 去掉分支卡却要求 `k ≥ 3`。`2 × n` 且只有直管和弯头的水管谜题到底能不能在多项式内求解？目前依然未知。
2. **`2 × n` 棋盘且全部为 `L` 卡（纯弯管）**：连直管都不给，只准拐弯，在 2 行棋盘上的可解性。
3. **宽度固定而高度无界（`w = O(1), h → ∞`）且允许无限空白卡**：这在实际电子游戏（比如经典接水管游戏 Pipe Mania）里极常见，但形式化复杂度依然未闭合。

读这篇论文最大的收获，是深刻体会到在网格图复杂性证明中，**「欧拉回路（局部度数平衡）」与「哈密顿回路（单次完全覆盖）」的转换往往只隔着一层卡片是否有剩余的薄纱**。而在处理全局连通约束时，前沿线 DP 把全局无环压缩成边界重编号的技术，也是我们在做组合谜题形式化时极具参考价值的标杆套路。
